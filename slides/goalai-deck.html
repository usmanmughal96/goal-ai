⚽ Computer Vision Penalty Simulator

GOAL AI

Webcam Gesture Edition  ·  By M Usman Mughal

A real-time football penalty kick simulator that uses your webcam and hand gesture tracking — running entirely in the browser, no server needed.

01 — Overview

What Is GOAL AI?

GOAL AI puts you on the penalty spot. Position your hand in front of the camera, aim at the goal, and throw a thumbs-up gesture to strike. A smart AI goalkeeper reacts in real time.

60 FPS Gameplay
0ms Server Round-trips
21 Hand Landmarks Tracked
3 Difficulty Levels

04 — Features

Key Features

🤚

Thumbs-Up Kick

Make a thumbs-up gesture to fire a shot. Landmark 4 (thumb tip) and fold-count logic make it reliable and false-positive-free.

🎯

Dynamic Aim

Your wrist position maps directly to the goal. Move left/right/up/down to aim anywhere on the frame.

🤖

Goalkeeper AI

The keeper reacts with difficulty-scaled speed and dive radius. Three levels: easy, medium, hard.

🔊

Stadium Synth Audio

Procedural crowd buzz, whistle, and post-thud sounds via the Web Audio API — zero audio files shipped.

05 — How to Play

Play in 3 Steps

1

Allow Camera Access

The game requests your webcam on load. No video is recorded or sent anywhere — all processing is local in the browser.

2

Position Your Hand

Hold your hand up in front of the camera. The real-time PIP overlay shows where your hand is being tracked on the pitch.

3

Thumbs Up to Shoot

Fold your four fingers and raise your thumb. The game detects the gesture and fires a shot based on your wrist position.

06 — Project Structure

App Architecture

🎮

GameArena

Main game loop. Handles physics, ball trajectory, goalkeeper AI, scoring, and 60 FPS canvas rendering.

🧠

CV Engine

src/utils/cvEngine.ts — wraps MediaPipe + optical-flow fallback. Emits landmark data and flick vectors.

🧙

SetupWizard

Calibration flow for sensitivity, zone, difficulty, and goalkeeper colour before entering the arena.

🏆

Leaderboard

In-session high-score tracking with difficulty filter and animated new-entry insertion.

📢

SocialShare

End-of-match share card generator with score, streak, difficulty badge, and goalkeeper jersey colour.

🔊

Audio Utils

src/utils/audio.ts — procedural synth sounds. Whistle, crowd, goal celebration, post hit.

07 — Getting Started

Run & Deploy

💻

Local Dev

npm install
npm run dev

Serves on port 5000. Hot-module replacement enabled. No env vars needed.

🚀

Production Build

npm run build

Outputs to dist/ in ~4 seconds. Deployed as a static site on Replit — no server required.

🔑

No API Keys

Despite using @google/genai as a dependency, the app runs fully offline. Hand tracking is done in-browser via MediaPipe WASM.

🌍

Browser Support

Any modern desktop browser with WebGL + WebAssembly support. Camera required for gesture control; mouse/touch works as fallback.
